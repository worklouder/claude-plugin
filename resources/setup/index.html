01

Connect Input

Checking…

Keep the Input app open with your device connected. Approve Work Louder for Claude Code when Input asks.

02

Add the controls

Waiting

Connect Input to see the active device profile.

The Claude Code layer adds six Agent Keys, encoder menu navigation, joystick session switching and scrolling, Review Changes, New Chat, Approve, Decline, model controls, and microphone controls. Your existing layers stay in place.

03

Start Claude

After setup

Start Claude Code normally in Terminal, iTerm2 or Ghostty 1.4 or later. Agent Keys 1–6 follow your open sessions and the joystick moves between them.

$claude
This page and its connection stay on your computer. Input owns the device connection.
